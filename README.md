MyStyle - AI Virtual Try-On Platform

Overview

MyStyle is a full-stack AI-powered virtual try-on platform that allows users to upload their photo and a clothing image, then generate an AI-transformed fashion look.

The project combines modern web technologies with AI image generation to provide an interactive virtual styling experience.

Key Functionalities

Upload Images

Users can upload:

- Personal Image
- Outfit Image

Generate AI Look

The uploaded images are processed through an AI virtual try-on workflow to create a new styled image.

Compare Results

Users can visually compare:

- Original Image
- AI Generated Image

Save History

Generated looks are stored and displayed inside the user profile.
